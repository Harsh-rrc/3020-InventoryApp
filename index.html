Inventory Management System

Website successfully deployed via GitHub Actions to S3

This is the frontend for the COMP-3020 Inventory App project.

The backend consists of Lambda functions and API Gateway endpoints that manage inventory data in DynamoDB.

API Endpoints:

  • GET /item - List all inventory items
  • GET /item/{id} - Get specific item
  • POST /item - Add new item
  • DELETE /item/{id} - Delete item
  • GET /location/{id} - Get items by location

Backend powered by AWS Lambda + API Gateway + DynamoDB
